# 尘迹拉力 DUSTMARK

单机拉力赛游戏：4 个环境、12 条赛段（可正反跑、3 种天气）、6 辆车、三个赛季的生涯、单赛段和幽灵车计时挑战。Three.js + TypeScript，物理是自己写的，在 Chrome 里运行。

## 怎么开玩
克隆下来后直接运行 `./play.sh`（macOS，需要 Node.js 和 Google Chrome）：第一次会自动装依赖并构建。`尘迹拉力.app` 和 `builds/stable` 不在仓库里，要用的话分别运行 `scripts/make-app.sh` 和 `scripts/snapshot-stable.sh` 生成。

| 方式 | 说明 |
|---|---|
| 双击 `尘迹拉力.app` | 玩稳定版（`builds/stable`），等于 `./play-stable.sh`。App 由 `scripts/make-app.sh` 生成，没签名，第一次打开要在 Finder 里右键 › 打开。可以拖进"应用程序"或程序坞。 |
| `./play-stable.sh` | 稳定版，端口 5199，不受正在开发的代码影响 |
| `./play.sh` | 开发版：源码有改动就先构建，端口 5198 |

两个脚本都会用 Chrome 开一个无边框全屏窗口，同时起手机方向盘服务；关掉游戏窗口后服务自动退出。端口被别的程序占着时会自动换一个端口，不会去关掉别人的进程。需要 Node.js 和 Google Chrome。

## 操作
| 动作 | 键盘 | 手柄 | iPhone（见 `docs/PHONE.md`） |
|---|---|---|---|
| 转向 | ← → / A D | 左摇杆 | 转动手机 |
| 油门 / 刹车 | ↑ / W，↓ / S（停住后倒车） | RT / LT | 右半屏 / 左半屏 |
| 手刹 | 空格 | A | 左下红色按钮 |
| 轻踩（按住时油门 ≤50%、刹车 ≤45%、方向 ≤60%） | 左 Shift | — | — |
| 升挡 / 降挡（手动挡） | E / Q | X / B | 右上 / 左上 |
| 回到赛道（罚 5 秒） | R | Back | 顶部按钮 |
| 换视角 | C | Y | 顶部按钮 |
| 轨迹预测 | P | — | 顶部按钮 |
| 暂停 | Esc | Start | 顶部按钮 |
| 手机配对二维码 / 静音 / 隐藏 HUD | K / M / H | — | — |

键盘开法：**按住就行**——方向、油门、手刹都不用点按；想温柔一点按住左 Shift。按住方向 = 前轮用满抓地，松开方向键时车在滑会自己反打摆回来（硬核档没有这些辅助）。右 Shift、Ctrl 不绑定任何操作。

菜单用方向键、回车、Esc（手柄：十字键、A、B，Q / E 或 LB / RB 翻页）。

## 玩法
- **生涯**：单人闯关，三个赛季（入门组 → 经典组 → 顶级组），每季 4 站、每站 3 个赛段。每个赛段按用时拿金 / 银 / 铜（3 / 2 / 1 分），赛季攒够分数（8 / 6 / 6 分，满分 36）解锁下一组别和两台车。没有对手、没有车损。
- **单赛段**：任选已解锁的车、赛段、方向和天气。
- **计时挑战**：和自己这条赛段的最好成绩（半透明幽灵车）比，另有金银铜目标时间。
- 每个赛段结束后可以看回放（电视机位 / 追尾 / 直升机，C 切换）。
- 第一次开跑前有一张"怎么开"卡片，设置 › 控制里可以重看。

## 设置里值得知道的
- **驾驶 › 辅助档位**：新手（ABS + 牵引力控制 + 稳定辅助）/ 标准 / 硬核。刚上手建议新手。
- **手感**（暂停菜单里也能直接进）：抓地、漂移角上限、推头保护、方向键速度、轻踩比例五个滑条，每个下面写着调大 / 调小会怎样，有"恢复默认"。下次开跑或重跑时生效；URL 里写了同名参数（`grip= slipcap= push= steerrate= gentle=`）时以 URL 为准。奖牌线和分段参考按默认手感计算。
- **赛事 › 领航提前量、领航声音**：美佳（台湾口音，默认）或婷婷（普通话）。
- **画面**：画质预设、渲染比例、动态分辨率、速度模糊等；"HUD 精简"只留计时、速度和下一条路书。
- **控制 › 手机方向盘**：显示配对二维码（要用 `./play.sh` 或 `./play-stable.sh` 启动）。
- **存档 › 清除存档**：清空生涯、纪录、幽灵车和设置。

## 常见问题
| 现象 | 处理 |
|---|---|
| 双击 App 提示"无法验证开发者" | 在 Finder 里右键 App › 打开，再点"打开"。 |
| 提示"没找到 Google Chrome" | 安装 Chrome；或者把终端里打印的地址复制到别的浏览器（没测过）。 |
| 提示端口被占用、换了端口 | 正常，游戏照常打开。想知道是谁占着：`lsof -nP -iTCP:5199 -sTCP:LISTEN`。 |
| 没有声音 | 进游戏后按任意键（浏览器要求先有一次按键才能出声）；M 是静音开关。 |
| 卡顿 | 设置 › 画面 › 画质预设改成"性能"，或者打开动态分辨率。 |
| 手机连不上 | 见 `docs/PHONE.md`。 |
| 稳定版太旧 | `scripts/snapshot-stable.sh` 跑完测试和冒烟后把当前代码做成新的稳定版（上一版留在 `builds/prev`）。 |

## 开发命令
| 命令 | 作用 |
|---|---|
| `npm run dev` | Vite 开发服务器（端口 5177） |
| `npm test` | 类型检查 + vitest（确定性、赛段、物理探针、生涯规则、手机协议…） |
| `npm run smoke` / `npm run smoke -- --full` | 无头浏览器走真实菜单：单赛段、生涯第一站（`--full`：整个生涯三季到结局）、计时挑战 + 幽灵车、回放三机位、设置刷新后保留、清除存档 |
| `npm run loadtime` | 首屏到可操作、菜单进赛段的时间（冷 / 热缓存） |
| `npm run bot -- --stage north-1 --car kestrel` | Node 里机器人跑一条赛段 |
| `npm run botmatrix [-- --keys]` | 所有赛段 × 六车的机器人矩阵 |
| `npm run calibrate` | 模拟键盘玩家的用时分布（奖牌线校准） |
| `npm run opptimes` | 重新生成奖牌线 / 分段参考用的预算机器人成绩表 `src/app/botTimes.json` |
| `npm run probe` | 手感探针 |
| `npm run bench` | 帧时间测试 |
| `npm run shots` / `tour` / `envshots` / `carshots` / `uishots` / `hudshots` / `camshots` | 各类无头截图 |
| `npm run camcheck` | 追尾相机穿地 / 回放电视机位遮挡检查 |
| `scripts/snapshot-stable.sh` | 出稳定版到 `builds/stable` |
| `scripts/make-app.sh` | 生成 `尘迹拉力.app` |

工具默认用 5177（开发服务器）和 5223–5226（各自起的构建服务），不碰 5198 / 5199。

## 目录
```
src/sim/      纯逻辑（车辆物理、赛段生成、机器人、赛事规则、存档），Node 里也能跑
src/render/   Three.js 渲染（地形、植被、车模、粒子、相机、后处理）
src/audio/    引擎声合成、路噪、领航员
src/ui/       菜单、HUD、结算（原生 DOM）
src/app/      主循环、输入、设置、回放、机器人参考成绩
src/data/     车辆、环境、赛段脚本、路面表
pad/          iPhone 方向盘页面
scripts/      启动、服务、截图、测试工具
public/assets 美术和语音成品；art/ 出图脚本
docs/         设计（DESIGN.md）、验收清单（ACCEPTANCE.md）、手机（PHONE.md）、截图
builds/       stable / prev 稳定版快照（不入库）
```
进度和每个里程碑的细节在 `PROGRESS.md`。
