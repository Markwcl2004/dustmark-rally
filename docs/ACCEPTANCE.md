# 验收清单

按顺序走一遍，每步对照"应该看到什么"。哪一步不对，记下步骤编号和看到的样子（能截图最好）。

## 1. 打开
双击 `~/rally/尘迹拉力.app`（第一次要右键 › 打开），或终端里 `cd ~/rally && ./play-stable.sh`。
- 3 秒内出现全屏标题画面，没有浏览器地址栏和标签页。
- 终端（用脚本启动时）打印一行 `[dustmark] game http://localhost:5199/ phone https://…/pad?k=…`。如果端口被占用，会说明换到了哪个端口。

## 2. 标题
- 满屏插画：林间砂石路上一台飞起来的拉力车，左下黑底色块写"尘迹拉力 DUSTMARK"，右下"按任意键开始"。
- 按任意键 → 三条斜色带扫过，进入主菜单；这一下之后游戏可以出声。

## 3. 新手卡（新存档第一次开跑时）
进任意赛段，倒计时开始前出现"怎么开"卡片，背后是已经加载好的起点。
- 左边按键表（方向键 / WASD、空格手刹、左 Shift 轻踩、E / Q 手动挡升降挡、R 回到赛道、C 视角、P 轨迹预测、Esc 暂停、K 手机方向盘、M 静音）。
- 右边四个路书示例图标（右四、左二、发卡右、直角左）和三句读法；"基本开法"是"按住就行：方向、油门、手刹都不用点按；想温柔一点按住左 Shift。"加一句"慢进快出"。
- 底部"辅助档位"：从生涯第一站进来时选的是"新手（推荐）"，← → 能改。
- 按任意别的键卡片消失，倒计时开始。再开新的赛段不会再出现；设置 › 控制 › 新手引导 可以重看。

## 4. 单赛段
主菜单 › 单赛段 › 选环境海报 › 选赛段、方向、天气、车、涂装 › 开跑。
- 加载时是一张拉力车插画，左下色块写环境名、赛段名、方向 · 天气 · 长度 · 车名，有进度条和一句小提示。4 秒内进入起点。
- 倒计时 3、2、1、GO；领航员（女声）报路，左上同时显示接下来三条路书图标，正在报的那条变黄。
- 上方计时器下面：最好还能拿的奖牌和目标时间（"金 3:12.40"），每公里一个分段对比（绿快红慢）。每行字都在深色底牌上，赤土高原的橙色天空、雪地里也看得清。
- 右下：转速灯、速度、挡位。左下一行按键提示。
- 冲过终点 → 结算卡：总用时、奖牌、罚时明细、最高 / 平均速度、个人最好和差值、下一档奖牌线差多少、每公里分段。按钮：继续 / 重跑 / 看回放 / 回菜单。

## 5. 生涯第一站
主菜单 › 生涯 › 选车（只能选入门组两台）。
单人闯关：没有对手、没有车损和维修区。
- 赛季总览：四站海报赛历（跑过的站显示三枚奖牌和得分），右边"赛季进度"：本赛季 x / y 分、进度条上的解锁刻度、"再拿 z 分解锁下一组别"、金银铜计数和计分规则（金 3、银 2、铜 1、完赛 0；第一季 8 分、第二 / 第三季 6 分）。
- 分站简报：三个赛段（SS1–3），跑过的写用时、奖牌、得分；下一个赛段的金 / 银 / 铜用时线；本站累计；赛季进度条。
- 每个赛段后结算卡上有奖牌和"+n 分"、本赛季分数进度、个人最好和差值；HUD 的分段对比是和个人最好（有的话）或下一档奖牌线比，不出现人名。"继续"直接进下一个赛段的简报。
- 三段跑完：分站结算（三段的用时、奖牌、得分，本站总分和总用时），回到总览时进度更新。
- 赛季结算：总分对门槛，够了解锁下一组别和两台车（第三季：生涯冠军 → 结局），不够就"重赛本季"。

## 6. 车库
主菜单 › 车库。
- 左边 3D 转台，右边纸卡：组别、驱动、功率、车重、0–100、极速、四条性能条、三套涂装。
- 没解锁的车是黑色剪影 + 锁 + 解锁条件。

## 7. 计时挑战和幽灵车
主菜单 › 计时挑战 › 选赛段 › 开跑，跑完一次后再跑同一赛段同一方向。
- 第二次前方有一台半透明的蓝色车（上一次的你），计时器下写"幽灵 +2.5"之类的实时差距。
- 挑战设置页显示这条赛段的幽灵车成绩和金银铜目标时间。

## 8. 回放
任一结算卡 › 看回放。
- 默认电视机位：路边的固定机位跟拍、按距离变焦，镜头不应被树、土坡、草挡住；挡住时会切到下一个机位或直升机视角。
- C 依次切换 电视机位 → 追尾 → 直升机。空格暂停、← → 跳 5 秒、↑ ↓ 调速度（0.25–4×），可以拖进度条。
- 有引擎声和路噪（按录下来的转速和油门播放）；计时挑战里有幽灵车的话，回放里也能看到它。Esc 回到结算卡。

## 9. 设置
主菜单 › 设置（Q / E 翻页）。驾驶 / 手感 / 赛事 / 声音 / 画面 / 控制 / 存档七页。
- 每页改一项，退出再重开游戏，改动都还在。
- 手感页：抓地、漂移角上限、推头保护、方向键速度、轻踩比例五个滑条，每个下面一行"调大 / 调小会怎样"，底部"恢复默认"。顶部小字"奖牌线和分段参考按默认手感计算"。
- 抓地调到 1.30 → 开一个赛段，弯里明显更抓；暂停 › 手感 › 恢复默认 › 重跑，回到原来的手感。暂停菜单里有"手感"一项直接进这一页。
- 控制页键位一览和暂停页右侧：左 Shift = 轻踩，E / Q = 手动挡升 / 降挡，没有 Shift / Ctrl 换挡；有一句"按住就行：方向、油门、手刹都不用点按；想温柔一点按住左 Shift。"
- 画面页有"速度模糊"开关。
- 存档页"清除存档"有确认框；清除后回到标题，生涯、纪录、幽灵车都没了，新手卡会再出现一次。

## 10. 手机方向盘
按 `docs/PHONE.md` 的步骤：游戏里按 K 出二维码 → iPhone 相机扫码 → 过证书警告 → 点开始 → 允许"动作与方向" → 横握。

## 只有真人能判断、自动化没验证过的事
1. **键盘手感**：高速过弯会不会太容易滑、油门 / 手刹是否好控制、发卡弯能不能用手刹甩过去。键盘操作全部"按住"即可。觉得不对就到 设置 › 手感（或暂停 › 手感）调：太滑 → 抓地调大；甩尾收得太早 / 太晚 → 漂移角上限；过弯觉得油门被掐 → 推头保护调小；方向太慢 / 太冲 → 方向键速度。告诉我最后停在哪几个数。
2. **六辆车的引擎声像不像车**：岭雀 / 津桥是高转四缸，洛川是化油器老四缸，赤峰是五缸涡轮（哨声可能偏大），雁山 / 海岱是现代涡轮四缸。全部只做过频谱检查，没人听过。不像就告诉我是哪台、像什么（电钻、蜜蜂…）。
3. **领航语音**：语速是否太快、"左 / 右"是否听得清。默认美佳是台湾口音，设置 › 赛事 › 领航声音 可切婷婷（普通话）。
4. **iPhone 真机五项**（`docs/PHONE.md` 开头）：证书和"动作与方向"权限、左右转方向对不对、显示的是 WebSocket 还是 HTTPS 备用通道和延迟、两个拇指同时按会不会误触、5 分钟会不会息屏。
5. **奖牌线体感**：第一赛季大概能拿到什么奖牌、金牌是不是要开得很干净才拿得到。奖牌线按机器人推算、用默认手感，校准见 `npm run calibrate`。
